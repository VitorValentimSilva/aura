# Convenção de commits

Este repositório usa mensagens no estilo `<tipo> <emoji opcional>: descrição`, como visto no histórico (`feat ✨: add new landing page component...`). Tipos comuns: `feat`, `fix`, `chore`, `docs`, `refactor`, `test`.

- Descreva o "porquê" quando não for óbvio pelo diff, não só o "o quê".
- Um commit por mudança logicamente coesa — evite misturar uma feature com uma correção não relacionada.
- PRs usam o template em `.github/pull_request_template.md`.
