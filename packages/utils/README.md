# aura-utils

Helpers genéricos, puros e testáveis, sem dependência de framework — usáveis em qualquer um dos três runtimes (Next.js, NestJS, edge).

O que não entra aqui: nada que dependa de env, de um SDK específico (Sentry, Upstash) ou de regras de negócio.

Consumido por: todos os apps e a maioria dos outros pacotes.
